Two safety nets, trusted differently

Everything teamroom knows arrives through one of two doors. One is guaranteed. The other depends on the model.

Git hooks

Always runs. Git calls it, not the model.

  • Fires after every commit, checkout, merge and rebase.
  • Sends the list of files this checkout has changed compared with main, including uncommitted and untracked ones.
  • Runs in the background. If the server is down, your commit still goes through.

MCP tools

Runs when the agent decides to call it.

  • teamroom_check_overlap asks who else is touching these files.
  • teamroom_report_work and teamroom_post_note share what the agent is doing.
  • teamroom_recent_activity reads the room before starting.

The hook is enforced. The tools are a request. The room stays accurate even when an agent ignores its instructions.

Where everything lives

A small server holds the room. Each checkout talks to it through the hooks and the CLI. Each agent talks to it through the MCP server running on the same machine.

Guaranteed: sent by git hooks Requested: called by the agent

What the room sees

Three kinds of entries. Each one carries a name, a branch and a list of file paths.

wip

Work in progress

Every file a checkout has changed but not merged yet. A new snapshot from the same checkout replaces the old one, so finished work stops showing up.

commit

Commits

The files one commit changed. Once that commit is on main, it no longer counts as overlap. It can't conflict anymore.

note

Notes

A sentence from a person or an agent, like "about to refactor auth/". Optionally tied to files.

File contents never leave your machine. The room gets paths, branch names, commit ids and short messages. Tokens are stored hashed on the server and kept in .git/teamroom.json on yours, readable only by you.

Get started

You need Node 20 or newer and a server your team can reach.

  1. Start a server

    npx teamroom serve --host 0.0.0.0 --port 8787

  2. Create a room from your repo

    teamroom create --server http://your-server:8787 \
  --room-name "Dark mode" --name alice
teamroom hooks install

  3. Teammates join with the command it prints

    teamroom join --server http://your-server:8787 \
  --room room_… --invite tri_… --name bob
teamroom hooks install

  4. Give your agent the tools

    claude mcp add teamroom -- teamroom mcp
codex mcp add teamroom -- teamroom mcp

  5. Check before you edit

    teamroom check            # your pending changes
teamroom check src/theme.ts
